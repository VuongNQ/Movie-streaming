# Manager App

Tauri manager app cho Movie Streaming.

## Tech stack

- React + TypeScript
- React Router
- Tailwind CSS
- React Query
- Firebase Firestore
- Tauri (Rust backend commands)

## Run

```bash
npm install
npm run build
npm run dev
```

## Environment

Tạo `.env` với:

```bash
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_GOOGLE_CLIENT_ID=
```
